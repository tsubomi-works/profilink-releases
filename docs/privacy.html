Profilink

プライバシーポリシー

Profilink は、お客様の個人情報を収集しません。以下はその詳細です。

アプリが集めないもの

  • お名前、メールアドレスなどの個人情報
  • 開いたリンクの URL、閲覧の履歴、使用状況の統計
  • ブラウザの中身（ページの内容、Cookie、パスワードなど）

リンクの振り分けは、すべてお使いの Mac の中だけで行われます。開いたリンクが外部に送信されることはありません。

アプリが読み取るもの

  • ブラウザのプロファイル一覧 — Chrome・Edge・Brave の Local State ファイルから、プロファイルの表示名・フォルダ名・ログイン中のメールアドレス・アイコンを読み取ります。選択画面と設定画面に表示するためだけに使い、外部には送りません
  • リンクを押したアプリ — リンクを渡してきたアプリ（Slack・メールなど）が何かを、macOS から受け取ります。「開いたアプリ」のルールと履歴のためだけに使い、外部には送りません

アプリが通信するとき

本アプリが外部と通信するのは、次の 1 つだけです。

  • アップデートの確認 — 1 日 1 回、GitHub（github.com）にある最新版の一覧を読み、新しいバージョンが出ているかを確認します。送信するのは通常の HTTP リクエストのみで、お客様を識別する情報は含みません。設定画面でオフにできます。

Mac に保存されるもの

  • 設定 — ルール、選択画面に出すプロファイルなど。~/Library/Application Support/Profilink に保存されます
  • 履歴 — 届いたリンクの URL、押したアプリ、開いた先、日時を、新しいものから最大 500 件。~/Library/Application Support/Profilink に保存されます。設定 › 履歴 で、いつでも消去したり、残さないようにしたりできます
  • ライセンスキーと試用期間の開始日 — macOS のキーチェーンに保存されます

どれも、お使いの Mac の中にとどまります。

購入したとき

決済は販売代行会社が処理します。カード番号などの決済情報は同社が扱い、当方は受け取りません。同社のプライバシーポリシーが適用されます。当方が知るのは、ライセンスの発行に必要な範囲のみです。

このウェブサイト

本サイトは GitHub Pages でホストされています。アクセスに伴い GitHub がログ（IP アドレス等）を取得します。当方は解析ツールや広告、Cookie を使用していません。
